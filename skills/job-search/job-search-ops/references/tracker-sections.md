# Running Job Opportunities Tracker — Required Sections

## Must Include
1. **Quick Stats** — Corporate | Nonprofit | Total; Applied | Interviews | Offers
2. **Top 5 Knockout Table** — Numbered, compact, one-row-per-job with direct Apply links
3. **Tier 1 Detail Cards** — Per-job tables: Comp, Location, Freshness, ATS link, Why, Status, Red Flags
4. **Tier 2 List** — Condensed format with red flag emphasis
5. **Excluded/Rejected** — Job name + rejection reason
6. **Application Pipeline** — Date | Job ID | Company | Role | Status | Follow-Up
7. **Action Items** — Checkboxes grouped: This Week Apply, LinkedIn Backlog, Prep, Maintenance
8. **Market Insights** — Hot trends, salary ranges, industries hiring, ATS dominance, watch-outs
9. **Goals** — Timeframe | Target | Status (use 🔴/🟢)
10. **Resources** — File paths for resumes, cover letters, prep guides created
11. **Cumulative Tracker** — All-time applications table (append row after each submission)
12. **LinkedIn Backlog** — From | Message | Date | Draft Ready?

## Freshness Requirements
- Every job MUST have a freshness field
- Exact when verifiable: "6 days ago (May 23) 🔥"
- "Unverified" if date not found
- Stale indicators: ⚠️ (>2 weeks), ⛔ (>1 month)
