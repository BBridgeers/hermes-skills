# Comprehensive Application Pack Format (JLL-Style)

**Gold standard format validated in session. Use for all Tier 1 applications.**

## Structure
1. **Verbatim Job Listing** — Copy job description exactly as posted. No paraphrasing. Preserve original bullet formatting.
2. **Match/Quality Analysis** — 5 subsections (A-E) showing direct alignment between candidate profile and each requirement area. Include quality percentages for 8-10 capability areas. Include 4-6 proof points with specific metrics.
3. **Skills Gap Analysis** — 2-4 honest gaps, each with "sell around" reframe strategy.
4. **Company/Product Overview** — 5W framework: WHO uses it, WHAT is it, WHEN/WHERE, WHY (strategic value, 8-12 bullets). Key features list.
5. **Tailored Resume** — Full text ready to copy into .docx. Include: Professional summary emphasizing role-specific keywords, core competencies (18-24, pipe-separated), professional experience with bullets rewritten for role alignment.
6. **Tailored Cover Letter** — 350-450 words. Opening expressing specific interest, achievement paragraph with 2-3 metrics, company fit, readiness, location advantage if applicable, closing.
7. **Interview Prep** — STAR stories (10 minimum, 150-250 words each), 30-60-90 day plan, elevator pitch, key metrics to anchor, critical Q&A topics.
8. **Status Block** — Track: Status, Resume version, Cover letter version, ATS link, Priority.
9. **Application Links** — Direct ATS URL, company careers page, hiring team contacts if identified.

## Minimum Word Counts
- Section 2 (Match Analysis): 500+ words
- Section 4 (Product Overview): 400+ words
- Section 8 (STAR Stories): 150-250 words each

## Never
- Leave {{VARIABLES}} unpopulated
- Use generic/template language
- Fabricate metrics or achievements
- Skip sections on Tier 1 applications
