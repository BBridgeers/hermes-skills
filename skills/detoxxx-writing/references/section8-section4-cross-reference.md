# Section 8 → Section 4 Cross-Reference Audit Methodology

## When To Use
After Section 8 pathways are V2-remapped, before Section 4 is considered complete.

## Audit Sequence

### Pass 1 — Missing Agent Detection
For each Section 8 pathway, extract every agent it mandates (with dose, phase, and companion agents). Query Section 4 grids for each agent. Flag all absences.

Common missing agents (May 22, 2026 audit):
- Glycine — 5 pathways demand it, often only in restoration phases
- Humic/Fulvic Acid — GO-metal prerequisite before chelators
- Zinc Carnosine — tight junction pair with L-glutamine
- Calcium D-Glucarate — Phase II glucuronidation
- Sulforaphane — Nrf2/proteasome
- Astragalus — Th1 rebalancing
- Cellulase + DNase I — biofilm enzyme cocktail

### Pass 2 — Agent Proximity & Synergy
For each Section 8 co-administration mandate, verify agents appear in the same time slot in Section 4.

Key pairs to verify:
- NAC + Glycine + Selenium (GSH synthesis triad)
- Nattokinase + Serrapeptase (must be co-administered on empty stomach per 8.8A)
- Iodine + Selenium (8.6C HARD GATE: iodine without selenium = thyroid oxidative stress)
- L-Glutamine + Zinc Carnosine (tight junction repair pair per 8.1D)
- DMSA + NAC (NAC before DMSA for renal protection)

### Pass 3 — Timing & Phase Placement
Verify each agent appears in the correct V2 phase and at the correct time of day.

### Pass 4 — CDS Proximity
Verify CDS 4h antioxidant separation. Verify no antioxidants (NAC, Vitamin C, GSH, ALA) appear in CDS windows.

### Pass 5 — Severity Classification
- CRITICAL: Sequence violations (enzymes before antimicrobials, drainage before mobilization)
- HIGH: Missing mandatory agents with HARD GATE prerequisites
- MEDIUM: Timing, proximity, dose mismatches
- LOW: Informational notes

## False Positive Filter — 8.8A Enzyme Pre-Treatment Rule
Section 8.8A mandates enzyme pre-treatment 14 days before antimicrobials. This applies to DEDICATED BIOFILM-DISRUPTION protocols (oregano oil, berberine, garlic against biofilm-embedded bacteria). It does NOT apply to Phase 2 antiparasitic botanicals (Black Walnut, Wormwood, Clove) which target free-swimming parasites via direct mechanisms. Do not flag Phase 2 as violating 8.8A.
