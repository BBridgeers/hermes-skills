## Key Patterns

**Bridge Box formula:** "Before you [action], you need to know [3 things]. This section is [metaphor]. Skip it and [consequence]. Read it [when]."

**Gate table pattern:** Gate # | Transition | Non-Negotiable Criteria — 7 rows, one per phase gate.

**Contraindication table pattern:** Condition | Mechanism | Risk — every restriction gets a biochemical justification.

**Red-Flag pattern:** Red Flag | What It Feels Like (sensory specificity) | Mechanism | Action — the "what it feels like" column is what makes this dual-track accessible.

**Escalate tier table:** Tier | Trigger | Action — GREEN/YELLOW/ORANGE/RED with color-coded severity.
