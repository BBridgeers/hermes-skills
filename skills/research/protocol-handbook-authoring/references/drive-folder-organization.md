# Drive Folder Organization for Handbook Sections

When uploading DETOXXX V2 Handbook content to Google Drive, organize in section-specific folders at the root of the DETOXXX V2 HANDBOOK DOCS folder (1QqFi4ouGDoLYaW8AkV4VN_CvMsuVzIEZ).

## Folder Structure

```
DETOXXX V2 HANDBOOK DOCS/
├── Section 8 — Synergistic Pathway Guide/
├── Section 9 — Personalization Factors & Triage/
├── Section 10 — Tracking Templates & Lab Protocols/
└── ... (one folder per section)
```

## Naming Convention

- Individual files: `section_X_Y_descriptive_name.md` (lowercase, underscores)
- Merged files: `Section_X_Merged.md` (at folder root)

## Merged File Creation

After uploading individual section files to a Drive folder:
1. Download all .md files in the folder (sorted by name)
2. Concatenate with `\n\n---\n\n` separator between files
3. Upload as `Section_X_Merged.md` to the same folder

## Never

- Nest section folders under wrapper folders (e.g., "Hermes Wave Output — Sections 8-9-10/")
- Create duplicate folders outside the Handbook Docs root
- Leave empty subfolders after moving files
