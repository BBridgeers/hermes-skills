# Output Directory Scan Fallback

## When to use this

After the mandatory secondary `find` verification returns only cron heartbeat sessions
(all [SILENT]), run one more pass: scan deliverable output directories for recently
modified files. A cron job can produce a substantive output file even when its session
summary says nothing noteworthy.

## The pattern

```bash
find /root/.hermes -type f -mmin -60 \
  -not -path '*/sessions/*' \
  -not -path '*/logs/*' \
  -not -name 'slack-context.md' \
  -not -name '*.db' -not -name '*.db-shm' -not -name '*.db-wal' \
  -not -path '*/cron/output/*' \
  -not -name '.tick.lock' -not -name '.usage.json' \
  -not -name 'channel_directory.json' -not -name 'heartbeat.log' \
  -printf '%T@ %p\n' 2>/dev/null | sort -rn | head -20
```

Exclude noise: session files, logs, SQLite WAL/SHM, cron output stubs, usage counters,
and the context file itself. What's left are actual deliverable artifacts.

## Key directories to check

| Directory | What it contains | Signal value |
|---|---|---|
| `~/.hermes/output/` | Named reports, sprint outputs, generated content | **HIGH** — these are the primary deliverable directory |
| `~/.hermes/articles/` | Digests, trending reports, content generation | **HIGH** — scheduled content pipelines write here |
| `~/.hermes/skills/*/references/` | Skill-level output and reference data | **MEDIUM** — indicates skill activity |
| `~/.hermes/skills/*/scripts/` | Script modifications | **LOW** — usually static |

## Production example

**2026-05-23 08:04 UTC heartbeat:**
- `sync-context.sh`: empty (exit 0)
- Session `find`: 3 non-cron sessions — all cron heartbeats returning [SILENT]
- **Broader file scan**: `housing-sprint-2026-05-23.md` (231 lines, 12KB) modified at 08:07
- **Result**: 9 ranked DFW housing listings generated by "Housing Sprint — Morning Search" cron
- **Verdict**: Would have been [SILENT] without the file scan. Real new content surfaced.

## Anti-pattern

Do NOT scan EVERY file on the filesystem. The output directories listed above
cover 95%+ of cron-generated deliverables. A wider scan produces noise.
